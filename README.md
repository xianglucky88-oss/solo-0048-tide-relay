# 潮标接力

打开页面即可开始。使用站点旁的指令控制台选择航行、校准、等候和充电。可用航路在图上高亮，右侧显示行动后的潮刻和余电。完成目标后返港交班；可以下载或重新载入一局指令。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4811`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 开局航图。显示站点、六刻潮表和可用航道。
- 整段潮窗。顺利入站并扣减电量。
- 补给。靠岸补电且不上溢。
- 校准。首次校准计分。
- 返港结算。返港后得到成绩。
- 记录回放。指令重放恢复相同状态。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。

## 自制航图与分享

用「导入航图」选择一份 JSON 航图即可开单船航次。航图需声明站点与起航台、信标与补给、航道（航时、耗电、开放与助流相位）、潮周期、电池容量、达标值和时限。

- 配置无效（标识重复、悬空引用、相位越界、航道从无完整开放段等）返回 400 并逐条列明原因；结构合法但无法在 50 条指令内达标返港返回 422。两种拒收都会保留当前航次与续航记录。
- 「保存指令」导出第 2 版自包含实录，内嵌开赛时的完整航图。把文件发给任何人，对方用「载入指令」就能按原航图复盘；航次未结束时可继续下令。
- 刷新页面、换浏览器，或之后另开同名同标识的新航图，旧实录仍按内嵌的开赛航图复盘，结果不变。内置「外湾夜班」与第 1 版旧实录照常使用。
- 可用 `npm run test:charts` 复跑自制航图与分享闭环的自动化检查。
