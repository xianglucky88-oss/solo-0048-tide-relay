# 潮标接力

打开页面即可开始。使用站点旁的指令控制台选择航行、校准、等候和充电。可用航路在图上高亮，右侧显示行动后的潮刻和余电。完成目标后返港交班；可以下载或重新载入一局指令。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4811`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 开局航图。显示站点、六刻潮表和可用航道。
- 整段潮窗。顺利入站并扣减电量。
- 补给。靠岸补电且不上溢。
- 校准。首次校准计分。
- 返港结算。返港后得到成绩。
- 记录回放。指令重放恢复相同状态。
- 多标签续航。同一浏览器多个标签从同一存档下令时，相同记录去重、前缀保留较长者、真正分叉并列保留；重开后比较候选航迹的位置、潮刻、电量和信标并选择一条，后续下令与下载都沿选中航迹进行。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载，`npm test` 运行归档合并与端到端续航测试。
