# 潮标接力

打开页面即可开始。使用站点旁的指令控制台选择航行、校准、等候和充电。可用航路在图上高亮，右侧显示行动后的潮刻和余电。完成目标后返港交班；可以下载或重新载入一局指令。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4811`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 开局航图。显示站点、六刻潮表和可用航道。
- 预报演练。开局给出两种航道安排与公布刻，公布前按共同指令走，公布后按实况分头返航。
- 按时交班预案。指定目标刻，取得公布前的下一条共同指令和公布后各自的航迹；无法保证时明确提示。
- 整段潮窗。顺利入站并扣减电量。
- 补给。靠岸补电且不上溢。
- 校准。首次校准计分。
- 返港结算。返港后得到成绩。
- 记录回放。指令重放恢复相同状态。

可参阅 `PROJECT_SPEC.md` 了解输入、规则、接口与演练机制。构建命令检查语法与服务装载。自动化测试套件留待后续。
